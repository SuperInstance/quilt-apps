❓ What-is-this? Demo

A demo Quilt app that uses the what-is-this overlay system.

This is a fake Quilt app. It exists to demonstrate the drop-in help overlay. Look at the bottom-right corner — see the pink ? button? Click it. That's the overlay. It works on every page that includes <script src="what-is-this.js"></script>.

Try the demo

Type your name below. The "Greeting" cell computes from "Name" — this is a real Quilt formula cell in action.

Hello, Casey! Welcome to Quilt.

↑ This is formula cell: {path:'greeting', kind:'formula', fn: ctx => 'Hello, ' + ctx.name + '! Welcome to Quilt.'}

How it works

The overlay is a single JS file (what-is-this.js, 7.5 KB, no deps). Drop it on any page and it adds itself — pink ? badge, modal with plain-English definitions, copy-to-clipboard embed snippet.

Add it to your app

Add this one line before </body>:

<script src="https://cdn.jsdelivr.net/gh/SuperInstance/quilt-apps/what-is-this.js"></script>

That's it. No build step. No dependencies. Self-contained.
